# 额度与计费

## 余额如何扣除

每次请求会根据模型价格、输入输出用量和账号分组倍率计算费用，并从账号余额中扣除。最终费用以控制台使用日志为准。

## 查看价格

[模型广场](https://newapi.fastapi.cool/pricing) 展示当前可用模型及价格。不同模型可能按 Token、请求次数、图片或音频时长计费。

## 充值与订阅

- 充值余额可用于按量调用。
- 订阅套餐可能包含有效期、可用模型或独立额度限制。
- 实际可用范围以购买页面显示为准。

## 额度说明

前台默认以美元金额展示余额。系统内部使用更小的额度单位进行精确结算，用户通常无需手动换算。

## 控制成本

建议在创建 API 密钥时设置：

- 单个密钥的额度上限
- 有效期
- 可用模型范围
- IP 白名单（如业务需要）

发生异常消耗时，应立即停用或删除相关密钥并检查使用日志。
