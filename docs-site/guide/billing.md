# 额度与计费

## 余额如何扣除

每次请求会根据模型价格、输入输出用量、实际命中的分组倍率以及可能产生的工具调用附加费计算费用，并从账号余额中扣除。最终费用以控制台使用日志为准。

## 查看价格

[模型广场](https://www.fastapi.cool/pricing) 展示当前可用模型、能力、支持协议及价格。不同模型可能按 Token、请求次数、图片、音频时长或动态规则计费。

对于按 Token 计费的模型，Web Search、File Search、图片生成等工具可能按实际调用次数产生附加费；按请求计费的模型通常不会重复收取这类工具费用。管理员可以调整工具单价，因此请以当前使用日志为准。

任务插件可以声明 `seconds`、分辨率、产品档位等计费用量字段和示例，管理员据此配置任务动态计费表达式。前端时间范围规则会将同日范围（例如 09:00–12:00）生成为同时满足起止边界的条件，将跨日范围（例如 21:00–06:00）生成为跨午夜条件；起止相同不会被当作全天生效，无效小时、分钟或星期值会被拒绝。

## 钱包、充值与订阅

新版控制台将相关功能集中在 [钱包](https://www.fastapi.cool/wallet)：

- 查看当前余额和账户额度；
- 使用已启用的支付方式充值；
- 购买或查看订阅套餐；
- 使用兑换码；
- 查看账单和充值记录；
- 查看邀请奖励并按规则转入余额。

不同站点配置下，部分卡片可能不会显示。订阅套餐可能包含有效期、模型限制或独立额度，实际范围以钱包页面为准。

创建支付前，系统会拒绝无法转换为有效额度、超出单笔范围或会使钱包超过安全上限的充值数量。支付成功后的订单状态与额度会原子更新，重复回调不会重复入账。

## 额度说明

前台可能按美元、人民币或 Token 显示额度，具体取决于站点设置。系统内部使用更小的额度单位进行精确结算，用户通常无需手动换算。

## 控制成本

建议在创建 API 密钥时设置：

- 单个密钥的额度上限
- 有效期
- 可用模型范围
- IP 白名单（如业务需要）

发生异常消耗时，应立即停用或删除相关密钥并检查使用日志。

## 核对扣费

最终扣费以 [使用日志](https://www.fastapi.cool/usage-logs/common) 为准。日志会显示模型、请求时间、输入输出用量、实际分组、reasoning effort、流式状态、耗时、消费额度和错误信息。动态计费详情会高亮本次实际命中的条件乘数；金额旁的工具图标表示包含工具调用附加费。Responses API 返回的缓存输入 Token 会从 `input_tokens_details.cached_tokens` 等兼容字段归一化，并按缓存倍率与未缓存输入分别结算，避免把同一批缓存 Token 再按普通输入重复计费。图片、视频等异步任务请同时检查 [任务日志](https://www.fastapi.cool/usage-logs/task)；插件任务详情会列出实际计费用量事实与可用产物，任务失败退款会同步回减已统计的用户与渠道用量。
