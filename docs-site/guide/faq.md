# 常见问题

## 401：未授权

检查 API 密钥是否完整、是否已被禁用，以及请求头是否为：

```http
Authorization: Bearer YOUR_API_KEY
```

## 403：没有权限

当前密钥可能无权访问该模型，或账号分组不支持该模型。请检查密钥的模型限制和账号权限。

## 404：接口不存在

检查 Base URL 和请求路径，常见错误是重复添加 `/v1`。

## 429：请求过多或额度不足

可能是余额不足、密钥额度耗尽、并发过高或触发频率限制。详细原因可在使用日志中查看。

## 5xx：服务异常

通常表示上游模型暂时不可用或网络异常。可稍后重试；持续出现时请保留请求时间、模型名称和日志中的请求 ID。

## 为什么同一模型费用不同

费用可能受输入长度、输出长度、缓存、图片数量、音频时长及账号分组倍率影响。

## 密钥泄露怎么办

立即在控制台停用或删除旧密钥，再创建新密钥。不要继续使用已经公开过的密钥。
