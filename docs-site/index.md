## 接入信息

| 项目 | 内容 |
| --- | --- |
| API 地址 | `https://newapi.fastapi.cool` |
| OpenAI Base URL | `https://newapi.fastapi.cool/v1` |
| API 密钥 | 在控制台的「API 密钥」页面创建 |
| 模型名称 | 以「模型广场」当前显示为准 |

::: tip

:::
