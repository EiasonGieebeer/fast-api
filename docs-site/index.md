## 接入信息

| 项目 | 内容 |
| --- | --- |
| API 地址 | `https://www.jetbrains.top` |
| OpenAI Base URL | `https://www.jetbrains.top/v1` |
| API 密钥 | 在控制台的「API 密钥」页面创建 |
| 模型名称 | 以「模型广场」当前显示为准 |

::: tip
首次使用建议先完成一次 [快速开始](/guide/getting-started)，确认密钥和模型均可正常调用。
:::
