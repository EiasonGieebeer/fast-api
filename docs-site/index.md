## 接入信息

| 项目 | 内容 |
| --- | --- |
| API 地址 | `https://www.fastapi.cool` |
| OpenAI Base URL | `https://www.fastapi.cool/v1` |
| API 密钥 | 在新版控制台的 [API 密钥](https://www.fastapi.cool/keys) 页面创建 |
| 模型名称 | 以 [模型广场](https://www.fastapi.cool/pricing) 当前显示为准 |
| 调用记录 | 在 [使用日志](https://www.fastapi.cool/usage-logs/common) 页面查看 |

::: tip
首次使用建议依次阅读 [快速开始](/guide/getting-started) 和 [新版控制台流程](/guide/console)，确认密钥、模型、余额和日志均正常。
:::
