# Fast API 隐私政策

**生效及更新日期：2026年7月2日**

我们重视个人信息保护，并按照合法、正当、必要、诚信和公开透明原则处理个人信息。

## 1. 我们收集的信息

为提供和保护服务，我们可能处理：

- 账户信息：邮箱、用户名、密码摘要、二次验证配置及账户状态；
- 使用与安全信息：IP 地址、设备和浏览器信息、登录及安全日志；
- API 记录：模型、请求时间、令牌用量、耗时、状态码、错误信息和请求标识等运行元数据；
- 交易信息：订单号、金额、支付状态及支付渠道返回的交易标识。我们通常不直接保存完整银行卡或支付账户凭证；
- 客服信息：您主动提交的邮件、问题描述及附件。

您的 API 输入可能被转发给所选上游模型服务商并为完成调用而处理。为排障、安全审计或履行法定义务，相关内容可能在必要范围内被临时处理或留存。请勿提交无权处理的个人信息、商业秘密或其他高度敏感数据。

## 2. 使用目的

我们将信息用于注册验证、身份认证、API 转发、计费结算、订单处理、客服支持、安全风控、防止滥用、故障排查、服务改进及履行法定义务。超出原目的使用时，我们将依法另行告知并在需要时取得同意。

## 3. 委托处理、共享与跨境

为实现服务，我们可能向必要的服务提供方传输相关信息，包括上游 AI 模型服务商、EasyPay/支付宝等支付渠道、QQ 邮箱 SMTP 服务、云计算和安全服务商。我们会要求其在约定目的和必要范围内处理。部分上游服务可能位于境外；涉及个人信息跨境时，我们将根据适用法律履行告知、单独同意或其他合规义务。除法律要求、保护重大权益或取得授权外，我们不向无关第三方出售个人信息。

## 4. 保存期限

我们仅在实现处理目的所需的最短期限内保存个人信息；交易、安全和审计记录可能依法律规定延长保存。期限届满后将删除或匿名化，法律另有规定或技术上难以立即删除的除外，此时仅进行必要的存储和安全保护。

## 5. 安全措施

我们采用访问控制、加密传输、凭证摘要或加密存储、日志审计、资源隔离和二次验证等措施。但互联网服务无法保证绝对安全；发生可能影响您权益的事件时，我们将依法处置和通知。

## 6. 您的权利

您可依法请求查阅、复制、更正、补充或删除个人信息，撤回同意、注销账户，或要求说明处理规则。撤回同意不影响此前处理的效力，部分必要信息被删除后相应服务可能无法继续提供。请通过下方邮箱提交请求，我们可能核验身份。

## 7. Cookie 与本地存储

本站可能使用 Cookie 或浏览器本地存储维持登录状态、保存界面偏好并保障安全。禁用必要存储可能导致部分功能不可用。

## 8. 未成年人

本站主要面向具备相应民事行为能力的用户。未满 18 周岁的用户应在监护人阅读同意并指导下使用；若发现未经适当授权处理未成年人信息，我们将依法处理。

## 9. 更新与联系

重大政策变更将通过站内公告、登录提示或注册邮箱告知。隐私咨询、权利请求和投诉请联系：[fast.api@qq.com](mailto:fast.api@qq.com)。请勿发送密码、API Key、验证码或 TOTP 密钥。
